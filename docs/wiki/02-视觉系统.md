# 视觉系统

当前站点采用「夜航实验室」方向：黑曜底色承托高亮信息，冰青和酸橙作为少量状态色，页面像一段可滚动的产品发布影片。首屏用超大渐变字、细网格和固定粒子场建立空间感，内容区用纵向透明遮罩保持文字可读，同时让背景在滚动时持续露出。

## 页面结构与动效

- `Hero` 使用 `motion/react` 的 `useScroll`，文字随离场进度产生垂直视差并淡出；CSS 叠加精细仪表网格与渐变标题。
- `SpatialCanvas` 固定在全页底层，桌面端 6000、移动端 2500 个粒子，使用 ShaderMaterial 做流动、鼠标排斥和滚动升降；粒子颜色为冰青、酸橙和冷蓝。
- `About`、`Projects`、`Contact` 继续使用 `.veil` 系列纵向遮罩，避免固定画布与高密度内容互相干扰。
- `VisualBreak` 通过逐字符 reveal 和上下位移形成中段节奏，作为长页面的呼吸区。
- `prefers-reduced-motion` 下关闭非必要动画并保留静态内容；Three.js 仍提供静态帧降级。
- 首屏提供纯 CSS 零 JS 依赖即时 Loading 动画（`#initial-loader`），采用与页面底色一致的 `#f5f5f7` 冷灰底色，包含呼吸绿点与平滑流动进度条；React 客户端挂载后通过 0.36s cubic-bezier 曲线平滑淡出并卸载。
- 预渲染 SEO DOM 节点（`.seo-prerender-container`）采用 W3C 规范的无障碍剪裁技术，文本与语义标签 100% 留存于 DOM 树供爬虫与大模型索引，在屏幕上零占位且不可见，彻底消除刷新时的预渲染文案跳闪。

## 项目卡片与分类交互

作品展示区采用分类筛选与阶梯展开：

- **分类与筛选**：支持 `全部作品`、`游戏工具`、`移动应用`、`Mac 工具` 四大分类，切换时带有动态胶囊背景过渡与卡片重排过渡。
- **展示规则**：前台仅渲染处于 `已上线` 与 `即将上线` 阶段的产品，初始展示 6 项（`PAGE_SIZE = 6`），超出时提供「查看更多作品」展开机制；`研究中`、`构思中` 与 `开发中` 项目默认在前台收起。
- **状态与排序优先级**：`即将上线`（优先级 0）居首，其次为 `已上线`（优先级 1），保证重点新产品获得首屏视觉权重。
- **卡片反馈**：悬浮触发 `translateY(-6px)` 抬升、阴影扩散与外链箭头外推；具备可用链接的项目在新标签页打开，无链接时提示「持续完善中」或「敬请期待」，小程序项目触发独立扫码弹窗。
- **动效降级**：在系统开启减少动态效果（`prefers-reduced-motion`）时，自动关闭位移与缩放，平稳优雅降级。
