# 视觉系统

当前站点采用「夜航实验室」方向：黑曜底色承托高亮信息，冰青和酸橙作为少量状态色，页面像一段可滚动的产品发布影片。首屏用超大渐变字、细网格和固定粒子场建立空间感，内容区用纵向透明遮罩保持文字可读，同时让背景在滚动时持续露出。

## 设计令牌

定义在 `src/index.css` 的 `@theme` 中：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--color-paper` | `#06080b` | 页面基底 |
| `--color-paper-raised` | `#0d1117` | 面板与卡片 |
| `--color-paper-sunk` | `#030405` | 页脚收束 |
| `--color-ink` / `-2` / `-3` | `#f2f5f7` / `#a6b0ba` / `#6f7b87` | 三级文字 |

| `--color-sage` | `#7fe5dd` | 3D 粒子与空间光色 |

## 页面结构与动效

- `Hero` 使用 `motion/react` 的 `useScroll`，文字随离场进度产生垂直视差并淡出；CSS 叠加精细仪表网格与渐变标题。
- `SpatialCanvas` 固定在全页底层，桌面端 6000、移动端 2500 个粒子，使用 ShaderMaterial 做流动、鼠标排斥和滚动升降；粒子颜色已切换为冰青、酸橙和冷蓝。
- `About`、`Projects`、`Contact` 继续使用 `.veil` 系列纵向遮罩，避免固定画布与高密度内容互相干扰。
- `VisualBreak` 通过逐字符 reveal 和上下位移形成中段节奏，作为长页面的呼吸区。
- `prefers-reduced-motion` 下关闭非必要动画并保留静态内容；Three.js 仍提供静态帧降级。

## 项目卡片交互

项目卡片采用直接跳转的交互模式：点击卡片整卡，若项目具有 `demoUrl` 或 `repoUrl`，将会在新标签页中打开相应链接，且光标在卡片上悬浮时呈手型；若项目无任何链接配置，则点击卡片不做跳转、无反应，且光标为默认样式。演示链接和源码链接自身也配置了跳转，同时通过 `stopPropagation()` 防止多余冒泡。卡片底部根据是否具有链接，会相应提示「点击访问页面」或留白。
