# 视觉系统

当前站点采用「夜航实验室」方向：黑曜底色承托高亮信息，冰青和酸橙作为少量状态色，页面像一段可滚动的产品发布影片。首屏用超大渐变字、细网格和固定粒子场建立空间感，内容区用纵向透明遮罩保持文字可读，同时让背景在滚动时持续露出。

## 设计令牌

定义在 `src/index.css` 的 `@theme` 中：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--color-paper` | `#06080b` | 页面基底 |
| `--color-paper-raised` | `#0d1117` | 面板与卡片 |
| `--color-paper-sunk` | `#030405` | 页脚收束 |
| `--color-ink` / `-2` / `-3` | `#f2f5f7` / `#a6b0ba` / `#6f7b87` | 三级文字 |
| `--color-clay` | `#b9ff62` | 主要动作与高亮 |
| `--color-sage` | `#7fe5dd` | 3D 粒子与空间光色 |

## 页面结构与动效

- `Hero` 使用 `motion/react` 的 `useScroll`，文字随离场进度产生垂直视差并淡出；CSS 叠加精细仪表网格与渐变标题。
- `SpatialCanvas` 固定在全页底层，桌面端 6000、移动端 2500 个粒子，使用 ShaderMaterial 做流动、鼠标排斥和滚动升降；粒子颜色已切换为冰青、酸橙和冷蓝。
- `About`、`Projects`、`Contact` 继续使用 `.veil` 系列纵向遮罩，避免固定画布与高密度内容互相干扰。
- `VisualBreak` 通过逐字符 reveal 和上下位移形成中段节奏，作为长页面的呼吸区。
- `prefers-reduced-motion` 下关闭非必要动画并保留静态内容；Three.js 仍提供静态帧降级。

## 项目卡片交互

项目卡片支持整卡点击打开项目档案弹窗（`ProjectModal`），标题按钮为键盘可聚焦的触发控件（`aria-haspopup="dialog"`）。演示链接和源码链接调用 `stopPropagation()` 防止冒泡触发弹窗。卡片底部显示非交互提示文本「点击卡片查看档案」，右侧展示外部链接。

## 项目档案弹窗视觉

弹窗与主站同为暗色体系，直接使用原生令牌，**不经过** `index.css` 里那层把浅色类名改写成暗色的 `!important` 覆盖（覆盖层只作用于其他组件残留的 `stone`/`bg-white` 类名）：

- 面板：`linear-gradient(150deg, rgba(20,29,36,.97), rgba(8,11,15,.95))` 渐变底 + 冰青描边 `rgba(127,229,221,.20)` + 顶部环境光晕，与 `#projects article` 卡片同源。
- 吸顶栏：`rgba(9,12,16,.82)` 半透明 + `backdrop-blur` + `hairline` 底边；左侧 mono 微标签沿用「酸橙编号 + 灰色 slug」格式。
- 文字三级：标题 `ink`、正文 `ink-2`、标签与说明 `ink-3`；分区之间用 `hairline` 细线分隔而非卡片嵌套。
- 元信息四格：半透明白底 `bg-white/[0.03]` + `border-white/[0.08]`，状态值按 `statusTone` 映射着色（已上线 emerald、内测 teal、开发中 clay、研究中 sky、构思中 ink-3）并带状态点。
- 动作：主按钮为酸橙实心胶囊（与 Hero 主 CTA 同源，深字），次按钮与技术标签为半透明白底 + hairline 描边，hover 提亮到酸橙。
