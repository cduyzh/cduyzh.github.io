## 一分钟背景

- 技术栈：React 19 + TypeScript + Vite 6 + Tailwind CSS v4 + Three.js + Motion + Lenis。
- 部署：`.github/workflows/deploy.yml` 在推送到 `main` 时构建 `dist/` 并走 Actions 发布 Pages；但仓库的 Pages Source 当前被设成了「Deploy from a branch」，导致线上发的其实是源码，详见已知缺陷第 1 条。
- 产物分发：GitHub Release 上的 zip，由本地脚本生成并自校验。

## 近期变更主线

1. `feat` 改造项目卡片交互：去掉点击卡片后的作品集档案弹框（删除 ProjectModal），改为点击卡片直接跳转到项目演示或源码页面；对于无链接的项目，点击后无反应（去除了光标指针特效）。
2. `feat` 新增两个已上线项目（终局竞速档案站、终局血量趋势）到作品集最前，封面图取自线上站点真实截图。
3. `chore` 修复 `package-lock.json`，让 `npm ci` 重新可用（原先缺 `resolved`/`integrity` 字段，CI 一直靠 `|| npm install` 兜底）。
4. `perf` 把 Three.js 改成按需加载，入口 chunk 从 1001 kB 降到约 458 kB。
5. `docs` README 从部署说明改写为个人介绍。
6. `style` 重建视觉体系：分区遮罩让 3D 背景贯穿整页 + 玻璃材质重写 + 配色令牌化。
7. `build` 新增本地发布脚本，替代此前手敲的 `gh release create` 流程。
